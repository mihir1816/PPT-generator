### 2. End-to-End Flow Test

**Step A: Upload**
```bash
# Upload a PDF
curl -X POST http://localhost:8200/api/upload -F "file=@test_document.pdf"
# Save file_id

# Upload a DOCX
curl -X POST http://localhost:8200/api/upload -F "file=@test_document.docx"
# Save file_id

# Wait for processing
curl http://localhost:8200/api/upload/<file_id_1>
curl http://localhost:8200/api/upload/<file_id_2>
# Both should reach "completed"

# Verify documents indexed
curl http://localhost:8200/api/documents
# Both should show is_indexed: true
```

**Step B: Create Deck + Syllabus (no outline)**
```bash
curl -X POST http://localhost:8200/api/decks \
  -H "Content-Type: application/json" \
  -d '{
    "document_ids": ["<doc_id_1>", "<doc_id_2>"],
    "description": "Create a presentation about the key topics in these documents for intermediate students",
    "outline": null,
    "preferences": {"audience_level": "intermediate", "tone": "creative", "content_mode": "mixed"}
  }'
# Expected: syllabus with topics generated by LLM
```

**Step C: Syllabus Feedback**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/syllabus-feedback \
  -H "Content-Type: application/json" \
  -d '{"feedback": "Add a summary topic at the end and remove the second topic"}'
# Expected: updated syllabus
```

**Step D: Approve + Wait Gate**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/syllabus-approve
# Expected: ready_for_retrieval (if docs indexed) or waiting_for_indexing
```

**Step E: Retrieval**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/retrieve
# Expected: retrieval_complete with chunk counts
```

**Step F: Outline**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/generate-outline
# Expected: slide outline with multiple slides
```

**Step G: Slide Generation (SSE)**
```bash
curl -N -X POST http://localhost:8200/api/decks/<deck_id>/generate-slides
# Expected: SSE stream — slide_start, slide_content, slide_complete events per slide
# All slides generated, final event: generation_complete
```

**Step H: Slide Feedback**
```bash
curl -N -X POST http://localhost:8200/api/decks/<deck_id>/slide-feedback \
  -H "Content-Type: application/json" \
  -d '{"feedback": "Expand slide 2 with more examples"}'
# Expected: only slide 2 regenerated in SSE stream
```

**Step I: Undo**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/undo
# Expected: outline + slides reverted to pre-feedback state
```

**Step J: Export**
```bash
curl -X POST http://localhost:8200/api/decks/<deck_id>/export
# Expected: download_url returned
curl -o output.pptx "<download_url>"
# Expected: valid .pptx file
```

**Step K: Create Deck WITH Outline**
```bash

  -H "Content-Type: application/json" \
  -d '{
```

### 3. Edge Cases to Test

```
- Empty document (0 text extracted) → should show error, not crash
- Very large PDF (100+ pages) → should process without timeout
- File exceeding MAX_UPLOAD_SIZE_MB (50MB) → 413 error before storage
- URL that returns 404 → upload status "failed" with error message
- Feedback on non-existent slide → error response, not crash
- Export before slides generated → proper error response
- Multiple rapid feedback rounds → state stays consistent
- Unicode/special characters in description → handled correctly
- Deck with single slide → export works
- Table spanning 3 slides → continuation slides render correctly
- SSE disconnect mid-generation → frontend shows partial slides + Resume button
- Undo after feedback → outline AND slide content fully restored from snapshot
- Undo when no feedback rounds exist → proper error response
- Delete document → verify Qdrant vectors AND MinIO file cleaned up
- Delete deck → verify exported PPTX cleaned up from MinIO
- LLM returns <think>...</think> block → JSON parsing still succeeds
- Wait gate race: approve syllabus while indexing finishes simultaneously → exactly one transition
- Long feedback session (>1 hour between steps) → retrieval data still available (stored in DB, not Redis TTL)
```
